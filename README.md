# CampusHub

Android Application Development Assignment 2 demo built with Java and XML. It has Welcome, Login, Register, Forgot/Reset Password, Dashboard cards, Module detail, and Profile screens. Login/recovery are local simulations.

## Run in Android Studio
1. Extract this ZIP and open the CampusHub folder containing settings.gradle.
2. Allow Gradle sync; install JDK 17 and Android SDK 35 if prompted.
3. Select an emulator (API 23+) or connect a phone; press Run.
4. Demo login: any valid email such as student@example.com and password with at least 4 characters.
5. Cards open Timetable, Assignments, Attendance and Notices. Profile and logout are on the dashboard.

Uses explicit Intents, LinearLayout, GridLayout, and ConstraintLayout, strings.xml, and night-mode color resources. No backend or real email delivery.
